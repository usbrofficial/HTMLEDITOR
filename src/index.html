How HTML Editor works

1. Open or create a page

Use New to start from a template, or Open to load any .html file from your computer.

2. Click and type

The page is shown exactly as it will look in a browser. Click on any text to edit it, just like in a word processor. Use the toolbar to make text bold, change colors, alignment and more.

3. Add blocks

The Add to page panel on the left lists things you can add: headings, images, buttons, tables, videos… Click one to add it below the selected item, or drag it to the exact spot.

4. Fine-tune

When you click something, the Selected item panel on the right shows its options: link address, image file, colors, spacing, size… You can also move it up/down, duplicate or delete it.

5. Save and preview

The page always looks the way visitors will see it. Press Preview to try it out for real (buttons, menus and videos all work), then Edit to continue. Save writes a normal HTML file you can upload anywhere.

Optional: the code

If you ever want to see or edit the raw HTML, press Code in the toolbar. It's never required.
